#Lumina
es una pagina web diseñada para explorar el mundo del cine sin distracciones, donde puedes consultar sinopsis y detalles técnicos de tus películas favoritas de forma rápida. La página está pensada tanto para cinéfilos apasionados como para espectadores casuales que valoran el buen diseño. Quien visite esta plataforma encontrará una experiencia visualmente elegante, intuitiva y directa, ideal para aquellos que buscan inspiración y calidad al momento de elegir su próxima sesión de cine.

##stack
- javascript
- react
- node.js
- gsap (animaciones)
- tmbd api (datos de peliculas)
